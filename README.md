# Умный кредитный кабинет предпринимателя

Прототип цифрового кредитного конвейера для малого бизнеса — хакатон Альфа-Банка 2026.

## Быстрый запуск
    cp .env.example .env
    docker compose up --build

- Кабинет: http://localhost:8080
- API и Swagger: http://localhost:3000/api/docs

## Стек
React + Vite + Mantine · NestJS + Prisma + PostgreSQL · BullMQ + Redis · Fastify (моки) · Docker Compose

## Архитектурные решения

- **Монорепозиторий (pnpm workspaces)** — фронт, API, моки и скоринг в одном репозитории с общей версией зависимостей и одним CI.
- **Скоринг — отдельный пакет `@alfa/scoring`** без базы и сети: чистые функции, покрытые тестами на 7 тестовых компаниях. Решение воспроизводимо, в каждом результате записана версия правил.
- **Внешние системы — отдельный сервис `mock-external`** (ЕГРЮЛ, ФНС, БКИ, ПЭП, выдача). API обращается к нему через адаптер с таймаутом и повтором; для перехода на реальные интеграции меняется только адаптер.
- **Drizzle ORM вместо Prisma** — чистый TypeScript без загрузки бинарных движков: проект надёжно собирается в Docker в условиях нестабильной сети.
- **Суммы в копейках (целые числа)** — без ошибок округления чисел с плавающей точкой.
