# Сценарий демо

Живое демо на защите: четыре исхода конвейера за 5–6 минут (сценарии T1, T3, T5 и T7 из аналитики), ещё две минуты — в запасе на дозапрос документа и надёжность. Пароль всех демо-пользователей — `Demo2026!`.

## Подготовка (за 15 минут до выступления)

1. Свежий `main` и чистая база:
   ```bash
   git pull
   docker compose down -v
   docker compose up --build -d
   ```
   Через минуту проверьте http://localhost:3000/api/v1/health и откройте http://localhost:8080.
2. Прогоните проверку: `node scripts/smoke.mjs` — должно быть «Совпало 7 из 7». Smoke создаёт заявки, поэтому после него снова очистите базу: `docker compose down -v && docker compose up -d`.
3. Откройте два окна браузера: обычное — для клиента, инкогнито — для аналитика, чтобы входы не мешали друг другу. Масштаб 125%, уведомления выключены.
4. Держите открытым Postman с импортированной коллекцией [`docs/postman`](postman/) и выполненной папкой «0. Вход». Это запасной путь, если что-то сломается в интерфейсе.

Пауза между этапами конвейера — 1,5 секунды (`PIPELINE_STEP_MS`), от отправки до решения около 6–8 секунд: зал успевает увидеть, как меняются статусы. Если нужно быстрее, задайте `PIPELINE_STEP_MS=800` в `.env` и выполните `docker compose up -d` — Compose пересоздаст контейнер API с новым значением (`restart` новые переменные не подхватывает).

### Если остаётся время

- **Дозапрос документа (1 мин).** anna@demo.ru: оборудование 1 млн на 36 мес без счёта → «Нужны документы» → загрузить [`equipment-invoice.pdf`](postman/files/equipment-invoice.pdf) → заявка продолжается сама → «Одобрено».
- **Надёжность (1 мин).** В терминале `docker compose stop mock-external`, igor подаёт заявку → она уходит специалисту, в карточке аналитика видно, что внешние сервисы не ответили. Затем `docker compose start mock-external`. Второй вариант: `docker compose restart api` во время оценки — после перезапуска заявка продолжается с того же этапа.

Для отказа показывайте Козлова, а не «Ромашку». У «Ромашки» отказ по стоп-фактору, но в объяснении всё равно выводится посчитанный балл 760 и рейтинг A — на сцене это выглядит противоречиво.

## Если что-то пошло не так

| Проблема | Что делаем |
|---|---|
| Экран фронтенда не работает | Продолжаем тот же сценарий в Postman: папка с номером сценария, Run. Ответы API показывают те же статусы и тексты |
| На месте нет интернета или не собирается Docker | Образы собираем заранее (`docker compose build` дома). После этого `docker compose up` работает без сети |
| Базу «замусорили» на репетиции | `docker compose down -v && docker compose up -d` — чистые демо-данные за минуту |
| Не поднимается Docker на ноутбуке | Второй ноутбук с тем же запуском. Последний вариант — запись экрана полного прогона, сделанная заранее |
| Заявка «висит» в статусе | Обновить страницу. Если не помогло — `docker compose restart api`: конвейер продолжит заявку с того же этапа |
| Забыли пароль | `Demo2026!` у всех, логины — в [README](../README.md#демо-доступы) |
