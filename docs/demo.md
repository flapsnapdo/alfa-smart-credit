# Как посмотреть продукт

За 5 минут можно запустить прототип и пройти четыре исхода конвейера: одобрение, контрпредложение, решение специалиста и отказ. Пароль всех демо-пользователей — `Demo2026!`.

## Запуск

Нужен только Docker.

```bash
git clone https://github.com/flapsnapdo/alfa-smart-credit.git
cd alfa-smart-credit
docker compose up --build
```

Первая сборка занимает несколько минут. Когда http://localhost:3000/api/v1/health отвечает `{"status":"ok"}`, откройте кабинет: http://localhost:8080.

На экране входа есть кнопки быстрого входа за каждого демо-пользователя. После входа клиент попадает в «Мои заявки», новая заявка — кнопка «Получить финансирование».

Между этапами конвейера специально стоит пауза 1,5 секунды, чтобы было видно, как меняется статус. Решение приходит через 6–8 секунд после отправки, страница обновляется сама.

## 1. Одобрение и выдача — igor@demo.ru

1. «Получить финансирование» → «Закупить товар или подготовиться к сезону», 1 500 000 ₽ на 24 месяца. Кабинет подберёт оборотный кредит и покажет примерный платёж.
2. Компания — ООО «Северный склад»: данные сверяются с реестром. «Всё верно, продолжить» → отметьте согласие на запрос в БКИ → «Отправить заявку».
3. Статус меняется на глазах: проверка данных → проверка компании → оценка → **Одобрено**, 17% годовых, ≈ 74 200 ₽ в месяц.
4. Ниже — «Почему такое решение»: 840 баллов, рейтинг A, сильные стороны компании и история заявки.
5. «Перейти к условиям» → «Принять условия». Код подписи показан прямо в кабинете: по условиям кейса — без СМС. Введите его → **Средства выданы**.

## 2. Контрпредложение — olga@demo.ru

Ольга — бухгалтер, ведёт три компании.

1. «Купить оборудование или транспорт», 900 000 ₽ на 24 месяца, компания ООО «Хлебный дом». На шаге проверки приложите счёт — [`equipment-invoice.pdf`](postman/files/equipment-invoice.pdf). Если не приложить, банк сам запросит его после отправки.
2. Результат — **Предлагаем другие условия**: 900 000 ₽ на 30 месяцев или 820 000 ₽ на 24 месяца под 15%. Причина названа прямо: платежи по другим кредитам уже занимают 20% выручки.
3. В объяснении есть подсказка, как получить всю сумму на исходный срок. «Выбрать вариант» → выберите вариант → примите и подпишите договор.

## 3. Решение специалиста — olga@demo.ru и analyst@demo.ru

1. От Ольги: «Закупить товар или подготовиться к сезону», 2 000 000 ₽ на 24 месяца, ООО «СтройМастер» → **Заявку рассматривает специалист**. У компании 530 баллов, рейтинг C — такие заявки система сама не решает.
2. Войдите аналитиком в другом браузере или в окне инкогнито. Заявка в очереди. В карточке — баллы по каждому фактору и ответы реестра, ФНС и БКИ.
3. «Принять решение» → «Изменить условия» → 1 000 000 ₽ на 24 месяца. Комментарий обязателен: без него решение не сохранится.
4. В кабинете Ольги само появится предложение специалиста.

## 4. Отказ с объяснением — kozlov@demo.ru

«Не хватает денег до поступления оплаты», 300 000 ₽ на 12 месяцев, ИП Козлов → **Отказ**: 270 баллов, рейтинг D. Три причины простыми словами: были серьёзные просрочки, выручка снизилась за полгода, бизнес работает меньше года. В объяснении — что можно сделать, чтобы в следующий раз решение было другим.

## Ещё сценарии

- **Дозапрос документа.** anna@demo.ru, оборудование 1 000 000 ₽ на 36 месяцев, счёт не прикладывайте → **Нужны документы** → «Загрузить документы» → `equipment-invoice.pdf` → заявка продолжится сама → **Одобрено**, 15%.
- **Запрос документа аналитиком.** olga@demo.ru, ООО «Агротех», оборудование 8 000 000 ₽ на 60 месяцев; счёт на оборудование — тот же `equipment-invoice.pdf`. Сумма выше лимита авто-решения, заявка уходит специалисту. Аналитик в решении выбирает «Запросить документ» → отчётность, Ольга загружает [`financial-statements.pdf`](postman/files/financial-statements.pdf), конвейер проверяет заявку заново, аналитик одобряет.
- **Стоп-фактор.** kozlov@demo.ru, ООО «Ромашка»: компания ликвидирована, отказ при любой сумме.
- **Сбой внешнего сервиса.** Выполните `docker compose stop mock-external` и подайте любую заявку. Она не теряется, а уходит специалисту; аналитик видит, что реестр, ФНС и БКИ не ответили. Вернуть сервис: `docker compose start mock-external`.
- **Перезапуск посреди оценки.** Пока заявка в статусе «Оцениваем заявку», выполните `docker compose restart api`. После перезапуска заявка продолжится с того же этапа.

## Без интерфейса — через API

Все сценарии T1–T13 проходятся одной командой, пока проект запущен:

```bash
npx -y newman@6.2.1 run docs/postman/alfa-smart-credit.postman_collection.json
```

Ту же коллекцию можно импортировать в Postman — подробности в [test-scenarios.md](test-scenarios.md). Описание всех методов API — [openapi.yaml](openapi.yaml).

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Порт 3000, 4001, 8080 или 55432 занят | Остановите программу, которая его занимает, или поменяйте левую часть порта в `docker-compose.yml` |
| Хочется начать с чистыми данными | `docker compose down -v && docker compose up` |
| Заявка долго стоит в одном статусе | Обновите страницу. Если не помогло — `docker compose restart api`: конвейер продолжит заявку с того же этапа |
